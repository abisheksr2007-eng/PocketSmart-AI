# PocketSmart AI

PocketSmart AI is a Generative AI powered budget planning and recommendation application.

## Features

- User registration
- User login
- JWT authentication
- Home planner
- Party planner
- Jewelry planner
- Optional jewelry/outfit image upload
- AI/Gemini integration
- Mock marketplace catalog
- Recommendation history
- SQLite database
- FastAPI backend
- HTML/CSS/JavaScript frontend
- Automated tests

## Requirements

- Python 3.10+
- VS Code
- Internet connection for installing packages
- Optional Gemini API key

## Installation

Open the project folder in VS Code.

Create a virtual environment:

```bash
python -m venv .venv
```
